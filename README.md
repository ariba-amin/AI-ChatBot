# 🤖 Rule-Based AI Chatbot

A simple and interactive **Rule-Based AI Chatbot** built with Python and Streamlit. The chatbot uses predefined rules and conditional logic to understand user questions and provide appropriate responses.

## 📌 Overview

This project demonstrates how a basic rule-based chatbot works without using Machine Learning or Deep Learning.

The chatbot handles a set of predefined questions related to:

- Artificial Intelligence
- Machine Learning
- Deep Learning
- Python
- Data Science
- NLP
- Computer Vision
- Neural Networks
- Programming
- Databases
- SQL
- HTML & CSS
- APIs
- And more

It can also provide a detailed explanation of the chatbot project when asked.

## ✨ Features

- 💬 Interactive chat interface
- 🤖 Rule-based responses
- 📚 Predefined technical questions and answers
- 👋 Greeting handling
- 📖 Detailed project explanation
- ❓ Default response for unknown questions
- 🗑️ Clear chat functionality
- 🌐 Streamlit-based frontend

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
